# ReadEase – Professional Smart Reading Assistant

A modern, accessible web application designed to make reading and understanding digital information easier for everyone. Built with a professional design and powerful features.

## 🎯 Project Overview

ReadEase is an advanced reading assistant that helps users:
- **Read text aloud** using browser Text-to-Speech
- **Adjust font size** for optimal readability (12px–32px)
- **Switch between light and dark modes** for comfortable viewing
- **Simplify complex text** into easier-to-understand language
- **Copy text to clipboard** with one click
- **Download text** as a .txt file
- **View text statistics** (word count, reading time, etc.)

ReadEase is built for the **CTRL-V Hackathon** (November 2026), which focuses on using technology to remove barriers to information access.

## ✨ Features

### Core Features
✅ **Text Input** – Paste or type any text into the reading area  
✅ **Read Aloud** – Listen to text with browser Text-to-Speech  
✅ **Font Size Controls** – Increase or decrease text size (12px–32px)  
✅ **Light & Dark Mode** – Toggle between themes for comfortable reading  
✅ **Text Simplification** – Rewrite complex sentences into simpler language  

### Advanced Features
✅ **Copy to Clipboard** – Save text with one click  
✅ **Download as File** – Export text as .txt file  
✅ **Text Statistics** – View word count, character count, reading time, sentence count  
✅ **Character Counter** – Real-time character count in the input area  
✅ **Responsive Design** – Works on desktop, tablet, and mobile  
✅ **Accessibility** – High contrast, large typography, keyboard navigation  
✅ **Local Storage** – Remembers your font size and theme preference  
✅ **Professional Design** – Modern gradient UI with smooth animations
